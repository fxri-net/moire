## 1.0.9

> 2026-11-06 发布

### ✨ 新增功能

- 文档站 404 兜底页与导航规范校验

### 🔧 功能调整

- 页面标题「快速上手」统一为「快速开始」，全站链接文案同步

### ⚡ 优化改进

- 文档站校验补 404 两条断言（`search: false`、`sitemap.transformItems`），并在构建后核验产物
- 404 页加 `search: false`，不进入站内搜索索引
- 文档站分组名收敛为 开始 / 参考 / 原理 / 开发 / 帮助，拆掉「接入与运维」「适配与答疑」，常见问题与更新日志统一进「帮助」
- 404 页从站点地图过滤，避免被搜索引擎当正常页面收录

### 🐛 问题修复

- 产物断言改为从 `404.md` 读取一级标题比对搜索索引，避免改标题后检查静默失效
- 产物断言步骤改为显式经 node 执行，避免 Linux 上因缺执行位报 `EACCES`

## 1.0.0

> 2026-10-25 发布

### 🚨 重大变更

- 收敛为微内核加插件装配的单实例架构，全部能力挂在 `window.moire`
- 字段层与视图层改为 schema 驱动，替代 0.4 的链式部署器与链式访问器
- 全部枚举改为具名 code，移除数字模式码与数字属性
- 适配层收敛为 layui 单一实现，框架层不再直接调用平台 API

### ✨ 新增功能

- 产出 IIFE、ESM、类型声明与产物清单四类产物
- 接入 TypeScript 类型检查、ESLint、Prettier、Vitest 与统一验收脚本
- 补充 0.4 到 1.0 的迁移对照与三个最小示例
- 建立 changesets 与 `dist` 分支的发版和分发通道
