# 国际化

国际化把框架内所有面向用户的文案收进词条表，按语言键取值、按名插值，未命中时逐级回退。它只做键值到文本的映射，不负责日期、货币等本地化格式。

```js
moire.i18n.locale // 'zh-cn'
moire.i18n.t('list.total', { total: 42 }) // '共 42 条'
moire.i18n.join(['共 42 条', '第 1 / 3 页']) // 中文无分隔符
```

## I18n

| 成员        | 签名                                        | 说明                                   |
| ----------- | ------------------------------------------- | -------------------------------------- |
| `locale`    | `readonly string`                           | 当前语言，始终是归一后的标识           |
| `t`         | `(key, params?) => string`                  | 取词条并按名插值                       |
| `join`      | `(parts: readonly string[]) => string`      | 按当前语言的 `separator.join` 组合片段 |
| `setLocale` | `(locale: string) => void`                  | 切换语言，入参会先归一                 |
| `extend`    | `(locale: string, extra: Messages) => void` | 追加或覆盖词条                         |

`join` 的分隔符来自词条 `separator.join`：中文为空串，英文为一个空格。它适合拼接由框架片段与业务片段混排的句子。

## createI18n

| 选项     | 类型                       | 说明                           |
| -------- | -------------------------- | ------------------------------ |
| `locale` | `string`                   | 初始语言，缺省按运行环境探测   |
| `extra`  | `Record<string, Messages>` | 追加词条，按语言合并进内置词条 |

```ts
// 源码层装配：包产物只导出默认实例 moire.i18n
const i18n = createI18n({
  locale: 'en-us',
  extra: { 'en-us': { 'app.title': 'Demo' } },
})

i18n.t('app.title') // 'Demo'
```

每个实例持有独立词条副本，业务追加词条不会污染默认实例，也不会相互影响。日常接入直接用 `moire.i18n.extend` 追加词条即可，不必另建实例。

## 语言归一

语言标识先做一次归一：去空白、转小写、下划线换连字符；`zh` 开头一律收敛为 `zh-cn`，`en` 开头收敛为 `en-us`，其余原样保留以便业务自带语言；为空时取第一语言 `zh-cn`。

| 输入                     | 归一结果 |
| ------------------------ | -------- |
| `zh` / `zh-CN` / `zh_TW` | `zh-cn`  |
| `en` / `EN_us`           | `en-us`  |
| `ja-jp`                  | `ja-jp`  |
| `''`                     | `zh-cn`  |

初始语言缺省时先读 `document.documentElement.lang`，没有则取 `navigator.language`，都没有则回落 `zh-cn`。

::: warning `extend` 的语言键不做归一
`setLocale` 会归一入参，`extend` 与 `extra` 只是按原样键写入词条表。追加词条时请直接使用归一后的键（`zh-cn`、`en-us`），否则写入的语言与切换到的语言对不上，词条永远取不到。
:::

## 取值与回退

取词条按三级顺序：当前语言命中则用；否则回退到第一语言 `zh-cn`；两者都没有时原样返回键名。键名透出便于在页面上直接发现漏配的词条。

插值只替换 `{名字}` 形式的占位，名字由字母、数字、下划线组成；未提供的名字原样保留，不会渲染成 `undefined`。

```js
moire.i18n.t('schema.required', { label: '昵称' }) // '昵称不能为空'
moire.i18n.t('schema.required') // '{label}不能为空'
moire.i18n.t('not.exists') // 'not.exists'
```

## 内置词条

内置词条按领域点分命名，值一律是可直接展示的文本。

| 前缀             | 覆盖范围   | 代表键                                                                                                                        |
| ---------------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `separator.`     | 片段组合   | `separator.join`                                                                                                              |
| `time.unit.`     | 时长单位   | `time.unit.day`、`time.unit.month`、`time.unit.year`                                                                          |
| `http.`          | 请求异常   | `http.failed`、`http.network`                                                                                                 |
| `kernel.plugin.` | 插件装配   | `kernel.plugin.failed`、`kernel.plugin.missing`、`kernel.plugin.exists`、`kernel.plugin.cycle`                                |
| `field.`         | 字段与占位 | `field.duplicate`、`field.empty`、`field.placeholder.choice`、`field.placeholder.input`、`field.upload`、`field.unknown`      |
| `list.`          | 列表文案   | `list.empty`、`list.column.selection`、`list.page`、`list.total`                                                              |
| `schema.`        | 校验提示   | `schema.required`、`schema.type`、`schema.number`、`schema.pattern`、`schema.length.*`、`schema.range.*`、`schema.value.*`    |
| `tool.`          | 工具动作   | `tool.confirm.delete`、`tool.confirm.export`、`tool.delete.done`、`tool.*.missing`、`tool.message.empty`、`tool.select.empty` |
| `view.`          | 视图装配   | `view.fields`                                                                                                                 |

`schema.value.*` 用于把取值形态翻译成可读名词（数组、布尔值、数字、对象、字符串），由校验提示的 `{type}` 占位引用。

## 覆盖内置词条

业务需要改文案时追加同键即可覆盖，无需修改框架源码。

```js
moire.i18n.extend('zh-cn', {
  'list.empty': '还没有任何记录',
  'tool.confirm.delete': '删除后不可恢复，是否继续？',
})
```
