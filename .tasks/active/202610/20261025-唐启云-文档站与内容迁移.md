# 文档站内容迁移与美化、README 重写

计划位置：第 2 / 3 项　前置：变更集与历史日志重建

## 背景

项目只有 `docs/migration.md`、`docs/distribution.md` 两页散装文档，无站点结构、无首页、无 API 文档；`README.md` 承载了大量实现细节（产物表、可选依赖、验收步骤），与其入口定位不符。

## 实施方案

### 1. 文档站骨架

- 新增 `vitepress ^1.6.4` devDependency 与脚本 `docs:dev` / `docs:build` / `docs:preview`、`sync:changelog-doc`。
- `docs/.vitepress/config.mts`：`lang: zh-CN`、`base = process.env.VITEPRESS_BASE || '/moire/'`、`SITE_URL` / `REPO_URL` 环境变量注入（默认 GitHub 主仓库）、`lastUpdated: true`、本地搜索中文 translations、`outline: { level: [2, 3], label: '本页目录' }`、`docFooter` / `editLink` / `footer` / `socialLinks`。
- `docs/public/logo.svg` 站点图标与首页素材。

### 2. 页面内容（指南层扁平，API 面保留子目录）

| 页面 | 来源 |
| --- | --- |
| `docs/index.md` | 新建首页：hero + 能力特性 + 30 秒上手 + 文档索引 |
| `docs/getting-started.md` | README 的接入、打包产物、示例章节迁入 |
| `docs/architecture.md` | 微内核 / registry / notifier / 适配层边界 |
| `docs/enums.md` | 具名 code 枚举清单 |
| `docs/build.md` | 四类产物与构建链 |
| `docs/distribution.md` | 原 `docs/distribution.md` 迁移改写（subtree、离线产物包、script 直引） |
| `docs/migration.md` | 原 `docs/migration.md` 迁移改写（0.4 → 1.0 对照） |
| `docs/release.md` | 发版链路：`toolkit changelog version` → 人工润色 → `toolkit changelog --history format` → `pnpm sync:changelog-doc` → `pnpm verify` → 版本与日志单独提交 → 打 `vX.Y.Z` 标签 |
| `docs/api/*.md` | 按模块拆分的 API 参考 |
| `docs/adapters/layui.md` | layui 适配层用法与边界 |
| `docs/faq.md` | 常见问题 |
| `docs/changelog.md` | 由 `scripts/sync-changelog-doc.mjs` 从根 `CHANGELOG.md` 生成，禁止手改 |

### 3. 镜像脚本

`scripts/sync-changelog-doc.mjs`：剥离 BOM、CRLF→LF 归一、校验首行 H1、剥离标题、校验存在 `## x.y.z`、写入固定页头（frontmatter `outline: [2, 2]` + `# 更新日志` + 请勿手改说明），仅在直接执行时落盘。

### 4. README 重写

按入口页重构：logo + 徽章 + 一句话定位 + 能力矩阵 + 平台支持 + 文档索引 + 接入方式 + 环境要求 + 版权信息；实现细节全部指向文档站，不再在 README 重复产物表与验收步骤。

### 5. 忽略项

`.gitignore` 补 `docs/.vitepress/cache/`；`.prettierignore` 补 `.vitepress/cache`。

## 影响范围

- 新增：`docs/.vitepress/config.mts`、`docs/index.md`、`docs/*.md`、`docs/api/`、`docs/adapters/`、`docs/public/logo.svg`、`scripts/sync-changelog-doc.mjs`
- 修改：`README.md`、`package.json`、`pnpm-lock.yaml`、`.gitignore`、`.prettierignore`
- 删除：旧 `docs/migration.md`、`docs/distribution.md`（内容迁入新结构）

## 验证

- `pnpm docs:build` 通过且无死链
- `pnpm sync:changelog-doc` 生成 `docs/changelog.md` 与根 `CHANGELOG.md` 正文一致
- `pnpm verify` 通过
