# 适配与字段层

批次：第 3 批　计划位置：3 / 7　前置：内核与基础能力

## 背景

现有物料体系是 `material/elem/*` 的 facade + skin 双文件，按 `init → data → deploy → done → echo → reset → clean` 七步运行，但 jQuery 与 layui 直连散落约 197 处、覆盖 20 个文件，字段无法脱离 layui 单测；HTML 契约用 `fxy-*` 属性，其中 `fxy-type` 以 `1` / `2` / `3` 表示全选 / 清空 / 反选。本批把外部依赖收敛成唯一出口，并把字段层改为契约驱动。

## 实施方案

1. `src/adapters/layui`：把 `layui.*`、`$.toast`、`layx` 全部收敛为该目录唯一出口，对外暴露与内核解耦的适配接口；用 ESLint `no-restricted-imports` 禁止其他目录直接引用 layui 与 jQuery。
2. `src/schema`：定义表单与列表的声明式描述契约及校验规则，作为 fields 与 views 的共用中间层。
3. `src/fields`：定义 `FieldRenderer` / `FieldInstance` 契约、字段注册表，并把七步生命周期固化为内核可调度的固定顺序。
4. 内置字段集全量迁移：input、select、date、upload 等按新契约重写，渲染与回显分离。
5. HTML 契约改造：`fxy-*` 全部改为 `data-moire-*`，`fxy-type` 数字值改为 `SelectAction` 具名值。

## 影响范围

- 新增：`src/adapters/layui/`、`src/schema/`、`src/fields/`
- 新增 ESLint 依赖边界规则（内核与字段层不得直连 layui）
- 模板输出的 HTML 属性名与取值变更，接入方需按第 6 批对照表适配

## 验证方式

- `pnpm verify` 全绿
- 用 jsdom 对每个内置字段做渲染与回显单测，覆盖七步顺序
- ESLint 依赖边界规则可拦截反例（其他目录 import layui 时报错）
- schema 校验单测覆盖必填、类型、范围等约束
