# 验收门禁增强与双平台流水线

计划位置：第 3 / 3 项　前置：文档站内容迁移与美化、README 重写

## 背景

`scripts/verify.mjs` 只串行跑六个 npm script，不校验依赖安装状态、不报告工具链版本、不覆盖文档站构建；仓库无任何 CI 配置与 Node 版本锚点，本地与远端无共同门禁。

## 实施方案

### 1. 门禁增强（`scripts/verify.mjs`）

- 首步 `pnpm install --frozen-lockfile`，失败即中止（`fatal`）。
- 新增 `reportToolchain()`：读 `package.json.packageManager` 与 `.node-version` 对照当前运行时，只告警不拦截。
- 单测步骤钉 `TZ=UTC`，避免本地时区导致快照类断言漂移。
- 追加「文档站构建（死链检查）」步骤，并提供 `--skip-docs` 开关。
- 保持「步骤清单只有这一份真源」，CI 只调用 `pnpm verify` / `pnpm verify --skip-docs`，不另抄步骤枚举。

### 2. Node 版本锚点

新增 `.node-version`（`20.20.2`），与 `engines.node`、CI 镜像三方一致。

### 3. GitHub Actions

- `.github/workflows/ci.yml`：`check` job（ubuntu，全量 `pnpm verify`，`fetch-depth: 0` 供 `lastUpdated` 取 git 时间）+ `windows` job（`pnpm verify --skip-docs`）。
- `.github/workflows/deploy-docs.yml`：`on.push.branches: [main]`，不做 `paths` 过滤（站点输入不止 `docs/`，枚举必漏）；`permissions` 含 `contents` / `pages` / `id-token`；`concurrency: pages`；构建时注入 `VITEPRESS_BASE=/moire/`、`SITE_URL`、`REPO_URL`；`upload-pages-artifact` + `deploy-pages`。

### 4. GitLab CI

`.gitlab-ci.yml`：`stages: test / deploy`；`image: node:20.20.2` + `corepack enable`；`test` 跑 `pnpm verify`；`pages` 跑 `VITEPRESS_BASE=/moire/ pnpm docs:build` 后 `rm -rf public && mv docs/.vitepress/dist public`，`artifacts.paths: [public]`；不做 `changes` 过滤。

## 影响范围

- 新增：`.node-version`、`.github/workflows/ci.yml`、`.github/workflows/deploy-docs.yml`、`.gitlab-ci.yml`
- 修改：`scripts/verify.mjs`、`package.json`（如需脚本参数）

## 验证

- `pnpm verify` 全量通过
- `pnpm verify --skip-docs` 通过（模拟 windows job）
- `toolkit tasks check` 通过
