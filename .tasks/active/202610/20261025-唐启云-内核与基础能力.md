# 内核与基础能力

批次：第 2 批　计划位置：2 / 7　前置：工程基线与验收门禁

## 背景

现有核心是 `base/master.js` 一类的巨型命名空间：参数处理用 `'1.1.1'`～`'2.2.2'` 共 13 个数字模式字符串（实测框架与接入方均无调用点），URL 处理用 `'1.1'/'1.2'/'2.1'`，时间处理用 `'1.1'/'1.2'` 且调用方传布尔值导致毫秒分支永不可达；另有 `case '1.1'` 缺 `break`、`file.pathExt` 使用未声明全局、`text.explode` 隐式全局赋值等缺陷。本批一次性重建「枚举中心 + 微内核 + 基础工具」三层，为新链路提供地基。

## 实施方案

1. `src/enums.ts`：全部枚举以 `const` 对象 + `as const` + 同名类型联合表达，键 PascalCase、值 kebab-case，成员注释写「何时用」；覆盖 `MergeDirection`、`MergeMissing`、`MergeBlankAs`、`MergeNormalize`、`UrlMode`、`TimeUnit`、`PadSide`、`SelectAction`、`JsonOp`、`Variant`；提供 `assertNever()`；`Object.freeze` 后挂到 `window.moire.enum`。
2. `src/kernel`：定义 `MoirePlugin` 契约（`name` / `version` / `depends` / `setup` / `dispose`）、插件注册表、拓扑依赖排序、生命周期调度、错误边界（异常统一交 `Notifier` 上报），并以 `window.moire` 作为唯一装配点。
3. `src/utils`：类型判断、对象深合并、DOM、文本、URL、时间、文件七个模块；入参一律具名参数或枚举成员，禁止隐式全局与未声明变量。
4. 参数合并正交重写：把 13 个组合式数字码拆为 `mutate` / `direction` / `missing` / `blankAs` / `normalize` 五个正交维度，逐条给出旧码等价映射，并以表驱动单测覆盖 13 种旧行为。
5. `src/http`：请求封装、拦截器链、结果归一、错误转 `Notifier`；取消同步请求。
6. `src/i18n`：文案键化 + 具名插值，替换位置数组式 `lang([...])`。

## 影响范围

- 新增：`src/enums.ts`、`src/kernel/`、`src/utils/`、`src/http/`、`src/i18n/`
- 不触碰旧 `base/`、`view/` 目录，旧产物不受影响；旧代码清理留到第 5 批
- 新增公开面：`moire.enum.*`、`moire.use()`、`moire.utils.*`

## 验证方式

- `pnpm verify` 全绿
- 枚举单测逐个成员断言取值与冻结性，`assertNever` 覆盖未命中分支
- 参数合并表驱动单测覆盖 13 种旧码等价；URL、时间、填充、选择四类枚举各有正反例
- 内核单测覆盖插件注册、依赖排序、重复注册、错误边界
