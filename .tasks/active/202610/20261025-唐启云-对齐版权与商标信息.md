# 对齐版权与商标信息

批次：第 2 批（前置：抄录项目协作规范）

## 背景

本仓版权声明散落在 README、源码文件头与构建脚本三处，口径不一致（版权主体写「方弦研究所」、年份写「2017-2099」），且缺少独立的商标声明与法务声明文件。被参考仓库已有一套完整的版权信息组织方式（`NOTICE` + `TRADEMARK.md` + README 版权段 + `package.json` 元数据 + 源码文件头），抄录后本仓对外声明可自洽。

## 实施方案

1. 新增 `NOTICE`：首行为本仓包名，版权行 `Copyright © 2017-2026 唐启云. All rights reserved.`，含出品方、商标声明与许可不授予商标使用权，协议口径为 Apache License 2.0。
2. 新增 `TRADEMARK.md`：抄录商标声明全文（基本信息、第42类服务项目、权利状态、授权范围、使用规范、获取授权、侵权处理），许可名称改为 Apache License 2.0。
3. 改写 `README.md` 版权信息段为七行式（作者 / 出品 / 版权 / 网站 / 协议 / 商标 / 出品方说明），协议指向 `LICENSE`。
4. 修改 `package.json`：`author` 补为对象（name / email / url）、补 `repository`、补 `files` 白名单；`license` 保持 `Apache-2.0`。
5. 同步源码文件头：`base/copy.js` 版权头模板与约 60 个源文件的 `Copyright` 行统一为 `Copyright © 2017-2026 唐启云`。
6. 重新执行 `npm run build`，重建 `moire.min.js` 与 `moire.plugin.min.js`，使产物内嵌的版权头与新口径一致。

## 影响范围

- 新增：`NOTICE`、`TRADEMARK.md`
- 修改：`README.md`、`package.json`、`base/copy.js`、`base/` `view/` `build/` 下各源文件头，以及两个 min 构建产物
- `LICENSE` 保持 Apache-2.0 不动
- 仅改注释与元数据，不改任何运行逻辑

## 验证方式

- `npm run build` 通过，两个 min 产物重新生成
- `git diff` 抽检：源文件仅版权行变化，构建产物仅版权头与合并内容变化
- `toolkit tasks check` 的 error / warn 均为 0
